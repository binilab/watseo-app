# Google Play Data safety 답변표 (왔어)

> Play Console → 앱 콘텐츠 → 데이터 보안(Data safety) 양식 작성용 초안.
> 개인정보처리방침(`privacy-policy.html`)과 내용이 충돌하지 않도록 맞춰 작성했습니다.

## 양식 상단 공통 답변

| 질문 | 답변 |
|---|---|
| 이 앱이 사용자 데이터를 수집하거나 공유합니까? | **예 (수집함)** |
| 수집한 모든 데이터가 전송 중 암호화됩니까? | **예** (HTTPS/TLS) |
| 사용자가 데이터 삭제를 요청할 수 있습니까? | **예** (`delete-account.html` 이메일 요청) |
| 제3자에게 데이터를 "공유(transfer)"합니까? | **아니요** — Supabase/Firebase/Expo는 앱 운영을 위한 처리 위탁(서비스 제공자)이며 광고/제3자 판매 목적 전송 아님. 연결된 사람에게 상태 전달은 사용자가 직접 시작하는 앱 기능. |

> 참고: Google 정의상 "공유(Sharing)"는 제3자(회사)로의 전송을 의미합니다. 서비스 제공자가
> 우리 지시에 따라 처리하는 것은 "공유"에 해당하지 않으므로 각 항목의 Shared = No 로 둡니다.

## 수집 데이터 유형별 답변

| Play 데이터 유형 | 왔어 항목 | 수집 | 공유 | 필수/선택 | 목적 | 전송 암호화 | 삭제 요청 |
|---|---|---|---|---|---|---|---|
| Personal info → Email address | 이메일 주소 | 예 | 아니요 | 필수 | 계정 관리, 앱 기능 | 예 | 예 |
| Personal info → Name | 닉네임 | 예 | 아니요 | 필수 | 앱 기능(연결된 사람에게 표시) | 예 | 예 |
| Personal info → User IDs | 계정 식별자 | 예 | 아니요 | 필수 | 계정 관리, 앱 기능 | 예 | 예 |
| App activity → Other user-generated content | 도착 장소명, 귀가 상태, 도착 확인 기록, 시간 연장 요청 기록, 도움 요청 기록, 연결 관계 | 예 | 아니요 | 필수 | 앱 기능(도착 확인/상태 전달) | 예 | 예 |
| Device or other IDs | 푸시 알림 토큰 | 예 | 아니요 | 선택 | 앱 기능(알림) | 예 | 예 |

> "필수/선택" 기준: 핵심 기능 동작에 필요한 항목은 필수, 알림 토큰은 사용자가 알림을 준비할 때만
> 등록되므로 선택으로 표기.

## 수집하지 않는다고 명시할 항목 (중요)

| 항목 | 수집 여부 | 비고 |
|---|---|---|
| 위치 정보(정확/대략) | **수집 안 함** | 실시간 위치 공유/이동 경로 저장 없음 |
| 사진 및 동영상 | **수집 안 함** | 카메라는 QR 스캔에만 사용, 사진/동영상 저장 안 함 |
| 연락처 | **수집 안 함** | |
| 금융 정보 | **수집 안 함** | |
| 정확한 위치(Precise location) | **수집 안 함** | |

## 권한과 데이터 매핑

| 권한 | 사용 이유 | 데이터 수집으로 이어지는가 |
|---|---|---|
| 카메라(CAMERA) | 도착 장소 QR 코드 스캔 | 아니요(이미지 저장/수집 없음) |
| 알림 게시(POST_NOTIFICATIONS, Android 13+) | 도착 확인/필요한 알림 표시 | 푸시 토큰(Device or other IDs) |

## 일관성 점검 메모

- 개인정보처리방침의 "수집하는 정보" 표와 위 데이터 유형이 일치하는지 확인.
- "위치/사진·동영상 미수집" 문구가 privacy-policy.html 과 동일하게 유지되는지 확인.
- 삭제 요청 경로(`delete-account.html`)가 Play Console "데이터 삭제 URL"에 입력되었는지 확인.
