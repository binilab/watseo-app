# 스토어 등록정보 초안

## 앱 이름
왔어

## 짧은 설명 (80자 이내)
상세 위치 없이, 도착 상태만 함께 확인하는 귀가 확인 앱

## 긴 설명 (초안)
왔어는 귀가 중에 도착 장소에 잘 도착했는지를 QR로 확인하고,
연결된 사람에게 도착 상태와 필요한 알림만 전달하는 앱이에요.

이동 경로나 실시간 위치를 계속 공유하지 않아요.
상세 위치는 공유되지 않고, 도착 확인 상태와 필요한 알림만 전달돼요.

[이렇게 쓸 수 있어요]
• 자주 가는 도착 장소를 등록하고, 장소별 QR 코드를 만들어요.
• 귀가를 시작하고, 도착 장소의 QR을 확인해 도착을 알려요.
• 도착이 늦어질 것 같으면 시간 연장 요청을, 도움이 필요하면 도움 요청을 보낼 수 있어요.
• 연결된 사람은 도착 상태와 필요한 알림을 확인할 수 있어요.
• 귀가 기록을 다시 확인할 수 있어요.

[개인정보를 생각했어요]
• 상세 주소, 좌표, 이동 경로는 전달하지 않아요.
• 카메라는 QR 코드를 확인할 때만 사용해요. 사진이나 동영상을 저장하지 않아요.

## 앱 액세스 설명 (App access)
이 앱의 기능은 로그인 후 사용할 수 있습니다. 검수를 위해 아래 테스트 계정을 사용해 주세요.

- 로그인 방식: 이메일(및 소셜 로그인 준비 중)
- 테스트 이메일: `<TEST_EMAIL_PLACEHOLDER>`
- 테스트 비밀번호: `<TEST_PASSWORD_PLACEHOLDER>` (실제 값은 Play Console 에만 입력)

> 도착 확인 흐름 검수 시: 장소 등록 → QR 보기 → 귀가 시작 → QR 확인 → 도착 확인 완료 순서로 진행됩니다.
> 두 번째 계정이 필요하면(연결/상태 확인) 별도 테스트 계정을 함께 제공하세요.

## 테스트 계정 안내 문구 (검수팀 메모)
- 도착 확인은 2단계입니다: ① 장소 QR 스캔(또는 코드 직접 입력) → ② "도착 확인 완료" 버튼.
- 카메라 권한을 거부해도 QR 코드 값을 직접 입력해 진행할 수 있습니다.
- 실시간 위치 공유 기능은 없습니다.

## 카메라 권한 사용 사유
도착 장소에 붙여둔 QR 코드를 확인(스캔)하기 위해 카메라를 사용합니다.
사진이나 동영상을 촬영·저장하지 않습니다. 권한을 거부하면 코드 직접 입력으로 대체할 수 있습니다.

## 푸시 알림 사용 사유
도착 확인, 시간 연장 요청, 도움 요청 등 사용자가 연결한 사람에게 필요한 알림을 전달하기 위해 사용합니다.
